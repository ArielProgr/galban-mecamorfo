# OSINT - Redes Sociales

## Descripción
Recopila información pública de perfiles en LinkedIn, Twitter, Facebook para identificar empleados y relaciones.

## Herramientas
- theHarvester
- Sherlock
- social_searcher

## Comandos
```bash
theHarvester -d objetivo.com -b linkedin
sherlock username --timeout 1
```

## Indicadores de Éxito
- Perfiles encontrados
- Emails descubiertos
- Relaciones identificadas
